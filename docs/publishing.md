# 搜索索引同步

站点发布和搜索索引同步是两个独立步骤。站点生成并发布成功后，执行：

```bash
node tools/sync-algolia.cjs
```

脚本从当前 Hexo 配置读取应用和索引，凭据使用已有环境变量 `HEXO_ALGOLIA_INDEXING_KEY`，或 `ALGOLIA_ADMIN_API_KEY`；不把写入密钥写入配置或命令参数。

只索引已发布文章，沿用配置中的索引字段，并用文章路径的 SHA-1 作为稳定 objectID。先上传并等待任务完成，再移除旧记录，最后核对总数；保留现有索引设置。执行前须确认当前源码包含该索引应收录的完整文章集合。

项目安装了两套注册同名 `algolia` 命令的插件，直接执行 `hexo algolia` 可能选中不同实现；本脚本使用明确的客户端与字段处理实现，避免命令覆盖和重建缓存后重复收录。

仅本地预览时不运行此脚本。
