# 前端静态依赖

这些文件是原主题已启用依赖的站内副本，版本固定，避免页面功能依赖浮动 CDN 地址。

`source/vendor/manifest.json` 记录包名、版本、原始下载地址、许可证声明和每个资源的 SHA-256；各包目录保留上游许可证。图标 CSS 与字体保留上游相对目录。

更新时显式选择版本、核对许可证及哈希，再检查搜索、懒加载、图标、提示框、诗词和装饰效果。不要直接覆盖为未固定版本的 CDN 内容。

InstantSearch 仅在首次打开搜索弹窗时加载。不蒜子统计和今日诗词仍使用各自的外部服务。

兼容性说明：pangu 使用保留 `autoSpacingPage()` 和全局变量接口的 4.0.7 浏览器构建；jQuery 使用兼容现有 Fancybox 3 与 Share.js 的 3.7.1，避免浮动到新的主版本。
